# LUMEN-V v1.4

Sistema de orientación académica y profesional desarrollado por Tribeca Academia.

Cambios principales:
- Gallego como idioma por defecto.
- Selector de idioma para gallego, castellano, portugués, inglés, francés, polaco y alemán.
- Cuestionario presentado con una única pregunta visible por pantalla.
- Escala de respuesta reformulada: “No encaja conmigo” / “Encaja poco” / “Tengo dudas” / “Encaja bastante” / “Encaja mucho”.
- Eliminada la información visible sobre qué dimensión puntúa cada pregunta.
- Funciones de accesibilidad: fuente estándar, Comic Sans y OpenDyslexic si está instalada en el dispositivo; ayuda literal con glosario contextual al pasar el cursor por términos.
- El informe PDF mantiene encabezado con símbolo y marca LUMEN-V.
- Eliminada cualquier descarga JSON; solo impresión/guardado en PDF desde navegador.

Nota lingüística: la versión base está preparada para uso principal en gallego y castellano. Las demás lenguas quedan incorporadas como soporte funcional de interfaz e informe y deben revisarse por hablantes especializados antes de una publicación institucional definitiva.
